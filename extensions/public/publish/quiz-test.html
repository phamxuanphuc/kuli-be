Web Fundamentals Quiz

This page contains ready-made multiple-choice questions about HTML, CSS, JavaScript, accessibility, browser rendering, and web performance. Use it to test page scanning and quiz generation behavior.

Questions

1. What does semantic HTML primarily improve?

  1. Only visual styling
  2. Meaning, accessibility, and machine readability
  3. Server memory allocation
  4. Image compression quality

Correct answer: B. Semantic elements communicate meaning to browsers, assistive technology, and search systems.

2. Which CSS property creates a grid layout?

  1. display: grid
  2. position: grid
  3. layout: grid
  4. float: grid

Correct answer: A. CSS Grid starts with display: grid on the container.

3. What is the purpose of alt text on an image?

  1. To make images load faster
  2. To describe image content when the image cannot be seen
  3. To convert images into SVG
  4. To prevent layout shift automatically

Correct answer: B. Alt text supports screen readers and fallback content.

4. Which JavaScript API is commonly used to request JSON data from a server?

  1. fetch()
  2. querySelector()
  3. setTimeout()
  4. localStorage.clear()

Correct answer: A. fetch() sends network requests and can parse JSON responses.

5. What does Cumulative Layout Shift measure?

  1. Unexpected visual movement during page load
  2. Total JavaScript bundle size
  3. Number of HTTP redirects
  4. Database query duration

Correct answer: A. CLS tracks layout instability that disrupts user experience.

6. In the rendering diagram above, what comes after the DOM and CSSOM are available?

  1. Render tree creation
  2. DNS lookup
  3. Password hashing
  4. Git commit creation

Correct answer: A. Browser combines DOM and CSSOM into a render tree before layout and paint.
